  • 🔧
    แก้เพิ่มคำศัพท์ไม่ได้: modal ใช้ element ID ผิด ทำให้บันทึกไม่ได้ แก้ให้ตรงกับ HTML
  • 🧹
    แก้ Active state ค้างใน Navbar: ลบ class ที่ hardcode ให้ JS จัดการ active state ทั้งหมดผ่าน updateNavCapsuleState()
